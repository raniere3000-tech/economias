Carregue a base para começar

O painel lê os arquivos .xlsx direto do seu computador. Nada é enviado para a internet: os dados ficam guardados só neste navegador até você carregar uma base nova.

  1. Clique em 📁 Conectar pasta e escolha a pasta com os arquivos .xlsx. Nas próximas vezes, é só clicar em ↻ Atualizar.
  2. Também dá para usar 📄 Carregar arquivo com um único .xlsx que tenha todas as abas.
  3. Cada aba precisa ter NUM_LIGACAO, Referência, ULTIMO_CONTRATO, TIPO_FATURAMENTO e as colunas de faturamento e economias. Só as linhas com ULTIMO_CONTRATO = SIM entram.
Arraste os arquivos .xlsx para cá
